**UNOSAT code: FL20210729BGD**  This map illustrates satellite-detected surface waters in Chittagong division, Bangladesh as observed from a Sentinel-1 image acquired on 11 August 2021 at 05:48 local time.

This is a preliminary analysis and has not yet been validated in the field. Please send ground feedback to United Nations Satellite Centre (UNOSAT).
