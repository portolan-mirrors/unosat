UNOSAT damage-site points (one point per assessed structure or site) from 119 per-event collections, in one GeoParquet file with a shared set of columns: `event`, `event_code`, `collection`, `source_layer`, `source_file`, `license`, `damage_class`, `damage_class_code`, `sensor_date`, `sensor`, `confidence`, `assessment_epoch`, and 2D EPSG:4326 geometry. Rows carry their own `license` column. Included: CC BY-SA (as HDX states it, no version), CC BY 4.0, and CC BY 3.0 IGO. The 20 collections under CC BY-NC-SA 3.0 are left out; they are in their event subcatalogs. For every source column, use the per-event collection named in `collection`. Read [AGENTS.md](AGENTS.md) for the columns and query recipes.

## Processing Notes

Built by tools/combine.py from the per-event GeoParquet collections, with DuckDB (UNION ALL) and geoparquet-io (GeoParquet 2.0, no geometry repair, bbox column). `damage_class` is the label decoded from the source geodatabase domain where one exists, else the raw text when the source column holds text labels. `damage_class_code` is the raw value as text. Collections in EPSG:3857 or UTM were reprojected to EPSG:4326; Z values were dropped. Wide multi-epoch layers (one row per site, with columns `Main_Damage_Site_Class_2` to `_N`) take the highest-numbered epoch whose class is not null, and that epoch's date, sensor, and confidence; `assessment_epoch` records it (1 = the unnumbered columns). The row count equals the sum of the input collections.

## Known Issues

Class labels are not normalized across events: UNOSAT's domains and text exports spell the same class in different ways (for example, Destroyed and Completely Destroyed), and some domains number classes differently. `damage_class` is null where the source holds a numeric code with no domain to decode it (shapefile exports). A row's `license` is the license of its HDX dataset; a combined work under mixed licenses must meet each one, including share-alike for CC BY-SA rows.
