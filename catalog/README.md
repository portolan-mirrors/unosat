A mirror of the satellite-derived geodata that the United Nations Satellite Centre (UNOSAT) publishes on the [Humanitarian Data Exchange](https://data.humdata.org/organization/unosat): flood and water extents, damage assessments, shelter and camp mapping, landslides, and analysis extents for disasters and crises since 2010. Each event is a subcatalog, grouped by hazard and year. Inside an event, the source layers of one kind (for example, all damage-site point layers) are merged into one GeoParquet collection, with the source layer and file kept on every row. Licenses differ by dataset and are set on each collection. Read [AGENTS.md](AGENTS.md) before you query.
